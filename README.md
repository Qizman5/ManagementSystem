# Warehouse Management System

Система управління складом (ASP.NET Core Server + .NET MAUI Client).
 "Система для управління [Users, Items, Actions] з MVC-адмін-панеллю та
MAUI-застосунком".
## Структура проєкту
- **Server/ServerApp**: ASP.NET Core Empty (.NET 8)
- **Client/ClientApp**: .NET MAUI Client (.NET 8, Windows Target)
